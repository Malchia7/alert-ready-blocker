Subscribe to Test Calendar Install Airplane Mode Shortcut

Finish setup on your iPhone

  1. Go to Settings > Calendar > Accounts, tap the new subscribed calendar's account, and set Fetch New Data to Hourly (or Automatically/Push, if offered).
  2. Build (or install, once the button above has your shortcut link) one Shortcut that runs Find Calendar Events where Title is "Alert Ready Test" and Start Date is Today (limit 1), stops if nothing is found, and otherwise converts the found event's Start Date and End Date to Unix Time, Waits until Start, turns Airplane Mode On, Waits until End, then turns it Off. Shortcuts can't trigger directly off a calendar event's own time, so the Shortcut does the real waiting itself — the on/off timing always tracks whatever time the scraper actually found, never a fixed clock time.
  3. In the Shortcuts app, create one Personal Automation with a Time of Day trigger set safely before any historical test window (e.g. 1:00 PM), repeating weekly, set to Run Immediately (no confirmation). Its only job is to kick off the Shortcut above, which no-ops on days with no event. iOS limits how long a background automation can run, so if Airplane Mode doesn't flip automatically, open the Shortcut from the Shortcuts app and tap it by hand — it checks the clock itself and still does the right thing.
