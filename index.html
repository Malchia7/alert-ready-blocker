BC Alert Ready Blocker

Subscribe once, then never hear a test alert again.

Subscribe to Test Calendar Install "Create Alert Blocker Alarms" Install "Alert Blocker Alarm Trigger"

Finish setup on your iPhone

  1. Go to Settings > Calendar > Accounts, tap the new subscribed calendar's account, and set Fetch New Data to Hourly (or Automatically/Push, if offered).
  2. Install both Shortcuts above. Create Alert Blocker Alarms runs Find Calendar Events where Title is "Alert Ready Test" and Start Date is Today; if found, it creates two silent alarms from the event's real Start Date and End Date, named AlertBlockerOn and AlertBlockerOff. Alert Blocker Alarm Trigger runs Find Alarms for an alarm named AlertBlockerOn or AlertBlockerOff that is Not Is Enabled (iOS auto-disables an alarm once it fires, which is how this tells which one just went off), then sets Airplane Mode on or off to match. Alarms are OS-level, so this sidesteps iOS's limits on how long a background Shortcut can run — the Shortcut only has to do its work the instant the alarm fires.
  3. In the Shortcuts app, create two Personal Automations, both set to Run Immediately (no confirmation):
    • A Time of Day trigger at 8:00 AM, daily, running Create Alert Blocker Alarms. It no-ops on days with no test, so it's safe to leave running daily.
    • An Alarm trigger (fires whenever any alarm goes off), running Alert Blocker Alarm Trigger.
